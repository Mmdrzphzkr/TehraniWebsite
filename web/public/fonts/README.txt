Place Persian font files here (e.g., Vazirmatn-Regular.woff2).
Recommended steps:
1. Download Vazirmatn woff2 and woff files and copy them into this folder.
2. Uncomment @font-face block in styles/globals.css to load the font.

Example font files:
- Vazirmatn-Regular.woff2
- Vazirmatn-Bold.woff2

Do not commit font files with restricted licenses to public repos. If needed, add them via a private package or internal asset storage.
